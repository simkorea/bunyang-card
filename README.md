# 분양상담사 디지털 명함

분양 상담사 한 명당 페이지 한 장. 링크를 받은 사람이 3초 안에
얼굴·이름·연락 수단을 보고 바로 전화나 카카오톡을 누를 수 있게 만든 것이다.

## 상담사 추가하는 법 (Phase A — 지금 단계)

1. `index.html`을 `{슬러그}.html`로 복사한다
2. 파일 안의 `PROFILE` 객체만 갈아끼운다
3. 커밋·푸시하면 `https://.../{슬러그}.html`로 열린다

`PROFILE`의 모양은 나중에 Supabase `agent_cards` 테이블로 옮길 때
그대로 컬럼이 되도록 짜뒀다. 지금 DB를 만들지 않는 이유는 돈 낼 상담사가
실제로 있는지 아직 모르기 때문이다. 다섯 명까지는 손이 더 빠르다.

## 상담 접수

기존 현장들과 같은 Supabase `consultations` 테이블을 쓴다.
`source`는 `명함-{슬러그}` 형식이라 관리자 페이지에서 어느 명함으로
들어온 상담인지 바로 구분된다.

## 열람 집계

현장 사이트의 `adguard.js`를 **일부러 가져오지 않았다.** 그 스크립트는
접속이 몰리면 `document.body`를 비우고 차단 화면을 띄운다. 현장 랜딩에선
맞는 동작이지만 명함에선 사고다 — 단톡방에 뿌리면 같은 공용 IP에서
여러 명이 들어오는데 그때 진짜 고객이 빈 화면을 본다.

대신 `check_site_visit`을 부르되 **응답을 읽지 않는다.** 기록만 남는다.
관리자 페이지 "방문자 통계" 탭에 `명함-{슬러그}`로 자동으로 나온다.

## 아직 안 채운 것

`PROFILE` 안에 `TODO`로 표시해 뒀다. 비워두면 화면에서 알아서 감춰지거나
버튼이 비활성으로 나온다. 가짜로 채우지 않는다.

- `mobile` 개인 휴대폰
- `kakaoUrl` 1:1 오픈채팅 링크
- `photo` 프로필 사진 (`images/` 에 넣고 경로를 적는다)
- `creds` 경력·자격증 (비어 있으면 섹션이 통째로 숨는다)
